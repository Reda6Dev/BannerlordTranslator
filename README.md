# Bannerlord Auto-Translator ⚔️

أداة ذكية ومفتوحة المصدر لترجمة مودات لعبة Mount & Blade II: Bannerlord تلقائياً، مصممة خصيصاً لتسريع عملية التعريب مع الحفاظ على سلامة الأكواد البرمجية للعبة.

## 🔥 المميزات
* **الترجمة السياقية:** دعم محركات ترجمة متعددة (Google Translate, DeepL).
* **فاحص XML الذكي:** يحمي وسوم اللعبة ويمنع انهيارها (Crash) بعد الترجمة.
* **تخطي الأكواد:** يتعرف على المتغيرات الأصلية (مثل `{TARGET_CHARACTER}`) ويتركها دون ترجمة.
* **تراجع آمن (Rollback):** نظام ذكي لحذف الملفات غير المكتملة عند الإلغاء للحفاظ على نظافة مجلدات اللعبة.
* **محرر تفاعلي مدمج:** لمراجعة وتعديل النصوص يدوياً قبل الاعتماد النهائي.
